**Debugging Kernelia** es un prototipo de videojuego educativo 2D de aventura con elementos RPG, desarrollado como Proyecto de Título de Ingeniería Informática.

El proyecto busca explorar una forma más visual e interactiva de acercarse a conceptos informáticos abstractos, integrando el aprendizaje directamente en la **narrativa, los personajes y las mecánicas del juego**.


---

## Diseño educativo

Debugging Kernelia se basa en el concepto de **integración intrínseca del aprendizaje**.

Esto significa que los conceptos informáticos no se presentan únicamente mediante definiciones o cuestionarios, sino que forman parte de los problemas que el jugador debe comprender y resolver para avanzar.

Una de las mecánicas principales representa la **memoria RAM como un espacio interactivo**, donde diferentes procesos deben ser organizados dentro de la memoria disponible.

---

## Tecnologías

El proyecto está siendo desarrollado principalmente con:

* **GameMaker** - motor del videojuego.
* **GML (GameMaker Language)** - programación y lógica del juego.
* **Aseprite** - sprites, animaciones y recursos pixel art.
* **Git / GitHub** - control de versiones y organización del desarrollo.

La dirección visual combina **pixel art, aventura RPG y elementos tecnológicos**, buscando que cada reino tenga una identidad propia.
